VELVORIA LAUNDRY - MIDTRANS RETURN/SYNC FIX

Perubahan utama:
- Snap token request mengirim callbacks.finish dan callbacks.error ke URL aplikasi saat ini. Ini menghindari Finish URL lama seperti eventku1.test.
- PaymentReturnController::finish tidak mempercayai query transaction_status/status_code. Controller meminta status transaksi langsung ke Midtrans, memverifikasi signature/nominal melalui MidtransService, lalu mengarahkan pelanggan ke detail pesanan lokal.
- MidtransService memiliki syncTransactionStatus() sebagai fallback saat webhook tidak dapat mencapai localhost.

Pemasangan:
1. Backup proyek yang sedang dipakai.
2. Ekstrak isi folder VelvoriaLaundry ke folder proyek, timpa file yang sama.
3. Jangan timpa file .env milikmu.
4. Pastikan .env memakai Server Key dan Client Key dari environment Midtrans yang sama.
5. Jalankan: php -l app/Services/MidtransService.php
6. Jalankan: php -l app/Controllers/Payment/PaymentReturnController.php
7. Restart Apache, buat transaksi baru, lalu tes pembayaran Sandbox.

PENTING UNTUK LOCALHOST:
- Browser pelanggan dapat kembali ke localhost pada komputer yang sama karena callbacks.finish diarahkan ke baseURL aplikasi.
- Midtrans server tidak dapat mengirim webhook ke localhost. Untuk webhook real-time, gunakan HTTPS public tunnel/domain dan atur Payment Notification URL ke https://DOMAIN/payment/midtrans/notification.
- Fallback return melakukan GET Status ke Midtrans dari server lokal, sehingga status dapat disinkronkan saat browser kembali. Jangan tandai pembayaran lunas hanya dari query URL atau callback JavaScript.
- Jika memakai perangkat HP fisik, localhost pada HP menunjuk ke HP itu sendiri. Gunakan alamat LAN komputer atau HTTPS tunnel sebagai baseURL/callback.
