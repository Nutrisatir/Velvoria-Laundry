VELVORIA LAUNDRY - MIGRASI KE XAMPP APACHE (WINDOWS)
===================================================

TARGET URL:
  http://velvoria.test/

TARGET FOLDER:
  C:\xampp\htdocs\VelvoriaLaundry

PENTING:
- ZIP ini berisi source code, bukan folder vendor. Dependency dibuat di komputer melalui Composer.
- Jangan salin folder proyek ke C:\xampp\apache\htdocs; lokasi standar XAMPP adalah C:\xampp\htdocs.
- Jangan menaruh Server Key Midtrans di JavaScript atau mengirimkannya melalui chat.

A. PINDAHKAN SOURCE CODE
1. Backup database dan file .env proyek lama.
2. Ekstrak folder VelvoriaLaundry dari ZIP ke C:\xampp\htdocs\VelvoriaLaundry.
3. Pastikan file berikut ada:
   C:\xampp\htdocs\VelvoriaLaundry\public\index.php
   C:\xampp\htdocs\VelvoriaLaundry\composer.json

B. AKTIFKAN EKSTENSI PHP XAMPP
1. Buka C:\xampp\php\php.ini.
2. Pastikan extension_dir mengarah ke C:\xampp\php\ext, misalnya:
   extension_dir="C:\xampp\php\ext"
3. Aktifkan baris berikut jika masih diawali titik koma:
   extension=intl
   extension=mbstring
   extension=curl
   extension=mysqli
   extension=fileinfo
   extension=openssl
   extension=zip
4. Pastikan file C:\xampp\php\ext\php_intl.dll tersedia.
5. Simpan php.ini.

C. PASTIKAN TERMINAL MEMAKAI PHP XAMPP
Tutup semua terminal VS Code, buka terminal baru, lalu jalankan:
  where.exe php
  php --ini
  php -v

Baris pertama where.exe php harus C:\xampp\php\php.exe dan php --ini harus menunjuk C:\xampp\php\php.ini.
Jika belum, tambahkan C:\xampp\php ke Windows PATH dan letakkan di atas PHP Laragon, lalu buka ulang terminal.

D. PASANG DEPENDENCY
Di PowerShell:
  cd C:\xampp\htdocs\VelvoriaLaundry
  php -m | findstr /I intl
  composer --version
  composer install

ZIP ini tidak menyertakan vendor. Karena composer.lock belum tersedia, jika composer install menyatakan lock file tidak ada, jalankan:
  composer update --with-all-dependencies

Kemudian pastikan SDK Midtrans:
  composer require midtrans/midtrans-php
  composer dump-autoload
  Test-Path .\vendor\autoload.php
  Test-Path .\vendor\composer\InstalledVersions.php
  composer show midtrans/midtrans-php

Dua perintah Test-Path harus menghasilkan True.

E. KONFIGURASI APACHE VIRTUAL HOST
1. Buka C:\xampp\apache\conf\httpd.conf sebagai Administrator.
2. Pastikan baris berikut aktif (tidak diawali #):
   LoadModule rewrite_module modules/mod_rewrite.so
   Include conf/extra/httpd-vhosts.conf
3. Buka C:\xampp\apache\conf\extra\httpd-vhosts.conf.
4. Tambahkan isi file xampp\velvoria-vhost.conf dari ZIP ini.
5. Sesuaikan path jika lokasi proyek berbeda. Contoh konfigurasi mengasumsikan C:/xampp/htdocs/VelvoriaLaundry.
6. Jalankan Notepad sebagai Administrator, buka:
   C:\Windows\System32\drivers\etc\hosts
7. Tambahkan baris:
   127.0.0.1 velvoria.test
8. Simpan hosts.
9. Restart Apache dari XAMPP Control Panel.

F. DATABASE
1. Start MySQL dari XAMPP Control Panel.
2. Buka http://localhost/phpmyadmin.
3. Buat database bernama velvoria_laundry dengan collation utf8mb4_unicode_ci.
4. Buka file .env di root proyek. Sesuaikan database.default.* dengan akun MySQL lokal.
   Konfigurasi awal disiapkan untuk root tanpa password dan port 3306.
5. Import SQL database yang sesuai dengan versi proyek atau jalankan migration/seed sesuai dokumentasi proyek.
   Jangan import database kosong di atas database yang sudah berisi data.

G. MIDTRANS SANDBOX
Di file .env isi kredensial BARU dari dashboard Sandbox:
  midtrans.serverKey = "SB-Mid-server-..."
  midtrans.clientKey = "SB-Mid-client-..."
  midtrans.isProduction = false
  midtrans.isSanitized = true
  midtrans.is3ds = true

Server Key hanya untuk backend. Client Key boleh digunakan frontend sesuai integrasi Snap. Jangan commit .env ke Git.
Kredensial yang pernah dikirim dalam chat/screenshot harus di-revoke/regenerate dahulu.

H. UJI APLIKASI
1. Jalankan:
   cd C:\xampp\htdocs\VelvoriaLaundry
   php spark --version
2. Pastikan Apache dan MySQL berstatus Running di XAMPP.
3. Buka:
   http://velvoria.test/
4. Jika URL tidak resolve, jalankan PowerShell sebagai Administrator:
   ipconfig /flushdns
5. Jika Apache gagal start, periksa C:\xampp\apache\logs\error.log.

CATATAN URL:
- app.baseURL pada .env dan app/Config/App.php diset ke http://velvoria.test/.
- VirtualHost menunjuk langsung ke folder public, sehingga URL tidak perlu menambahkan /public atau /public/index.php.
- Asset, form action, redirect, route, dan URL callback internal yang memakai site_url()/base_url() akan mengikuti baseURL ini.
- Jika nama domain diganti, ubah app.baseURL pada .env dan app/Config/App.php, ServerName pada VirtualHost, serta hosts file.
