VELVORIA LAUNDRY - PATCH PEMBAYARAN MIDTRANS
=============================================

PENTING: hasil pemeriksaan pada screenshot menunjukkan:
HTTP 401 Unauthorized dari Midtrans Snap API saat backend membuat Snap Token.

Ini adalah penolakan autentikasi Midtrans. Bukan masalah Chrome, Snap.js,
CSRF, nominal order, atau tampilan popup. Midtrans menerima request dari
backend tetapi menolak Server Key yang dikirim.

Yang sudah diperbaiki dalam patch ini:
- Validasi awalan Server Key dan Client Key agar cocok dengan mode Sandbox/Production.
- Pesan error HTTP 401 dibuat spesifik agar tidak menyesatkan.
- Detail error tetap masuk ke writable/logs tanpa mencatat isi credential.
- .env sengaja TIDAK disertakan demi keamanan.
- Credential pada .env.example dikosongkan. Jangan gunakan key contoh.

CARA MEMASANG
-------------
1. Backup folder proyek VelvoriaLaundry.
2. Ekstrak ZIP ini ke lokasi proyek yang sama, misalnya:
   C:\xampp\htdocs\VelvoriaLaundry
   Pilih replace/overwrite untuk file yang sama.
3. Jangan menghapus atau menimpa file .env lokal yang sudah ada.
4. Buka file .env lokal dan ganti dua credential Midtrans dengan key asli
   dari SATU merchant/account yang sama di Midtrans Dashboard > Settings > Access Keys.
5. Untuk pengujian Sandbox, gunakan:
   midtrans.serverKey = "SB-Mid-server-KEY_ASLI"
   midtrans.clientKey = "SB-Mid-client-KEY_ASLI"
   midtrans.isProduction = false
   midtrans.isSanitized = true
   midtrans.is3ds = true
   Contoh di atas hanya pola prefix, bukan key yang bisa dipakai.
6. Simpan .env, restart Apache, lalu coba pembayaran lagi.

PENTING TENTANG HTTP 401
------------------------
- Server Key yang dipakai untuk membuat Snap Token adalah Server Key.
- Client Key tidak mengautentikasi request backend ke endpoint create Snap Token.
- Kedua key harus berasal dari merchant dan environment yang sama.
- Jangan memakai Production Server Key pada Sandbox, atau sebaliknya.
- Jika key sudah benar tetapi tetap 401, hubungi Midtrans Support untuk memeriksa
  status key/merchant. Jangan mengubah kode untuk melewati autentikasi.

KEAMANAN
--------
ZIP proyek yang dikirim sebelumnya berisi file .env dan credential Midtrans.
Anggap credential yang pernah dibagikan melalui ZIP sebagai terekspos.
Minta Midtrans Support melakukan rotasi/penggantian Server Key bila diperlukan,
kemudian perbarui .env lokal. Jangan mengirim .env atau Server Key ke siapa pun.

UJI SINTAKS
-----------
Dari terminal pada folder proyek jalankan:
  php -l app/Services/MidtransService.php

Hasil yang diharapkan:
  No syntax errors detected in app/Services/MidtransService.php

Setelah itu, uji tombol Bayar Sekarang. Jika kredensial diterima, endpoint
POST /customer/orders/{order_number}/pay seharusnya mengembalikan JSON success
dan snap_token. Popup Snap baru dapat dibuka setelah token berhasil dibuat.

Catatan:
Patch kode tidak dapat membuat Server Key yang tidak sah menjadi valid.
Keberhasilan transaksi tetap memerlukan key Sandbox yang sah dari Midtrans,
database aktif, koneksi server ke Midtrans, dan konfigurasi webhook yang benar.
